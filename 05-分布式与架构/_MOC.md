# 05 · 分布式与架构 · 内容地图

> **定位**：一致性模型、高可用、降级与切流、白板系统设计。
> 提醒：QPS/规模要诚实，**把能讲清的模式（状态机、最终一致、限流降级）说透** 优于硬凑数字。

---

## 子模块导航

### 一致性与事务
_CAP / BASE 要落到「你选的模型 + 怎么验收」_

_待补清单_
- 分布式事务方案对比：2PC / TCC / SAGA / 本地消息 / 最大努力通知
- 中心到多终端/边缘节点的下发与**最终一致**（版本号、ACK、补偿）
- 幂等 ID / 版本号 / ACK 机制
- 分布式锁的几种实现（Redis / ZK / DB）
- CRDT / 向量时钟的适用性判断
- 为什么微服务不要随便用分布式事务

### 高可用与容灾
_含库级迁移、双写/对账、切流、回滚 等可复用模式_

_待补清单_
- 多级时间桶/档位降级设计（T-k 日依赖的调度或跑批里常见）
- 核心库迁移方案：为什么迁 / 新老库同步 / 切流 / 回滚 / 业务无感知
- 双写期间的一致性校验与差异修复
- 灰度切流：按用户 / 按租户 / 按百分比
- 混沌工程 / 演练的价值与成本
- 雪崩预防：熔断 / 限流 / 降级

### 系统设计题
_白板题专用 · 用 [[_模板/系统设计题笔记]] 写_

_待补清单_
- 设计多档位依赖/降级调度体系（T-k 日桶）
- 设计多租户的 LLM 平台隔离（算力/配额/审计）
- 设计优先级任务队列
- 设计短链服务
- 设计秒杀系统
- 设计 RAG 问答系统
