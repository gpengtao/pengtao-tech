# 1on1 怎么聊出真问题

## 一句话速记

1on1 的核心不是"汇报进度"，是**挖出你不主动问就永远不会知道的事**。三个原则：① 让 TA 先说，你后说（至少前 15 分钟闭嘴）；② 问具体情境不问抽象评价（"上周哪个时刻你最沮丧"比"最近怎么样"管用 10 倍）；③ 记下来，下周回访——不跟进，1on1 只是一次聊天。

## 通俗解释（5 分钟版）

```
无效 1on1：
  你："最近怎么样？"   TA："还行。"
  你："项目顺利吗？"   TA："挺顺利的。"
  你："有什么问题吗？" TA："没什么。"
  你："好，那今天就到这。"
  → 浪费时间，双方都觉得在走形式

有效 1on1：
  你："上周你说那个接口联调很慢，后来解决了吗？"   TA："没，他们说排期到下个月…"
  你："卡在哪了？需要我出面协调吗？"              TA："其实他们 leader 不太好说话…"
  → 问题浮出来了，你可以介入
```

1on1 是 TL 最重要的工具——它不是开会，是你和 TA 之间**唯一的私密对话通道**。没有它，你只能看到产出的代码，看不到产出背后的阻碍、情绪和困惑。

## 关键细节

### 频率与节奏

```
频率：每周一次，雷打不动
时长：30 分钟（新人/最近有问题的可以 45 分钟）
时间：不要在周一早上（人还没进入状态）或周五下午（人已经在周末模式）
建议：周三/周四下午

取消规则：只能取消一次（连取消两次说明你不重视，TA 也会觉得你不在
          乎）；取消后必须 24 小时内 reschedule
```

### 问什么——问题清单

**破冰/建立连接**（前 5 分钟）：
```
不是所有人都愿意掏心掏肺。用具体问题降低回答门槛：

"这周有什么你觉得做得挺顺的事？"
"哪个时刻让你觉得最有成就感？"
"有没有什么事让你觉得特别烦或者特别累？"
"这周和谁合作得比较好？和谁不太顺？"
```

**挖阻力和困惑**（中间 15 分钟）：
```
"有什么事情在阻碍你推进？不一定是技术问题，流程、人、资源都算。"
"最近有没有什么决定让你觉得没太搞明白为什么这么做？"
"如果让你重新设计这个项目，你会改什么？"
"有没有你觉得应该做但没人说出来的事？"
```

**谈成长**（后 10 分钟）：
```
"上个月我们聊到的那个目标，你现在感觉怎么样了？"
"你觉得自己最近在哪个方面进步最大？"
"有什么你想学但一直没来得及学的？"
"你觉得我作为 TL，有什么该做但没做好的？"
```

### 关键技巧

**1. 追问"具体什么时候"**：
```
TA："最近沟通不太顺。"
你："什么时候的事？具体哪次让你觉得特别不顺？"
→ 从模糊抱怨变成具体事件，就能讨论怎么改了。
```

**2. 沉默不打断**：
```
你问完一个问题，TA 沉默了。
→ 别急着填充沉默。TA 可能在组织语言、在犹豫要不要说实话。
→ 等 5 秒。如果 TA 说"没什么"，可以换个角度：
  "感觉你犹豫了一下，是不是有什么你觉得不好说的？"
```

**3. 记下来，下周回访**：
```
每次 1on1 记 3 行笔记：
  - TA 提到的 1 个担忧
  - 你答应做的一件事
  - TA 说下周想完成的一件事

下周 1on1 的开场：
  "上周你说 XX 接口联调卡住了，现在怎么样了？"
→ TA 知道你是真的在听，不是走形式
```

**4. 不要做的事**：
```
✗ 把 1on1 变成进度汇报会（那是站会/daily standup 的事）
✗ 你一个人说超过 50% 的时间
✗ 在 1on1 里传达坏消息或 PUA（那是绩效面谈的事，不要混淆）
✗ 把 1on1 记到公开文档里（这是私密对话）
✗ 用电脑/手机（你的注意力是稀缺信号）
```

### 新人 vs 老兵的 1on1 差异

```
新人（入职 0-3 个月）：
  - 频率可以更高（一周两次）
  - 多问 onboarding 体验、融入感、工具/流程困惑
  - 多给积极反馈（新人容易自我怀疑）

老兵（1 年+）：
  - 多聊长期发展、职业方向、对团队/公司的看法
  - "你觉得自己下一个台阶是什么？"
  - "除了现在做的事，你还想接触什么？"
```

## 延伸追问

- **Q：1on1 聊到 TA 哭了怎么办？**
  → 停下来，不要慌张。说一句"我能理解这对你来说很不容易"，给 TA 几分钟消化。不要急着给解决方案，不要急着"我来帮你搞定"——有时候 TA 只是想说出来。当天不要继续追问，第二天可以问一句"昨天聊完你感觉怎么样"。
- **Q：TA 说的问题直接指向另一个 TL，我怎么处理？**
  → 不承诺站队。说"我了解了，让我想想怎么处理最合适"。你可以去找那个 TL 聊，但不能说"XXX 说你不好"。保护信息来源是 1on1 存活的底线。
- **Q：如果 TA 每次都只说"挺好的"怎么办？**
  → 可能是你还没建立信任，也可能 TA 性格内向。换问法："如果让你给这周的体验打分，1-10 分，你会打几分？"如果 TA 说 7 分，追一句"差的 3 分是什么？"

## 我的记法

- **三原则**：TA 说 > 你听（至少一半）→ 问具体不问抽象 → 记下来下周回访
- **最好的问题**："最近有什么让你特别烦的事？"
- **最不该做的事**：把 1on1 变成进度汇报
- 一句话：**「1on1 不是你获取信息的工具，是 TA 说出你该知道但不知道的事的通道」**
