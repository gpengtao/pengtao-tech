# 同事协作：冲突处理与高效协作要素

协作问题的核心能力：**把人际摩擦翻译成可诊断的原因→可执行的动作→可验证的结果**。

---

## 一、协作冲突怎么处理

### 1. 先诊断，再动手

大多数协作摩擦不是态度问题，是信息或结构问题。分三类根因：

```
① 不知道要做什么 → 需求/标准/接口没说清楚 → 补文档、补对齐会
② 不知道怎么配合 → 流程/职责边界模糊 → 拉通定 R&R、定交付契约
③ 知道但不想做 → 优先级冲突或激励不对 → 对齐优先级，理解对方 KPI

别把①当成③处理——多数「不想配合」其实是「不知道怎么配合」。
```

动手前先自查：**我有没有让对方很难合作的地方？**——信息没同步、需求没写清楚、临时改方案没有提前沟通。

### 2. 处理流程

```
自查 → 一对一（具体事例） → 无改善 → 再聊一次 → 仍无改善且影响里程碑 → 升级
```

**一对一**：
- 用具体事例开口（某次联调/变更/上线窗口），不说「你总是」
- 对齐四件事：共同目标 → 各自卡点 → 各自交付物 → 你能提供的支持
- 给对方退路——「可能是我信息不全，你看是不是我的理解有问题？」
- 能当面聊就别用文字，文字容易升级为对抗

**升级**（同一问题一对一聊过两次无改善，且开始影响里程碑时触发）：
- 定位为**项目风险管理**，不是告状
- 说清三要素：影响面 + 时间点 + 备选方案
- 不拉人站队，不扩大矛盾

### 3. 常见误区

- 默默忍到爆，不敢直接对话
- 跳过一对一直接找对方 leader 或 HR
- 给对方贴情绪标签（「奇葩」「情商低」）——标签一出，归因就停了
- 把协作问题拖成信任问题再处理

## 二、高效协作的基本要素

用**工作方式**定义好的协作，不用性格标签。现实中没有完美协作者，这四条是「最顺畅模式」的参考，差异靠机制兜底。

### 1. 对结果负责

时间/质量承诺明确，问题尽早暴露，不临近上线爆雷。
承诺了扛住，扛不住提前说——对自己和对协作方是同一标准。

### 2. 事实优先

需求、约束、风险、trade-off 摊开讨论。意见不合时，基于同一套信息做决策，而不是各说各话。主动把上下文和约束同步出去，降低别人的信息不对称。

### 3. 尊重专业边界

该谁拍板谁拍板，用数据和复盘代替「我觉得」。自己领域的决策承担后果，别人领域的不越界插手，但可以给信息输入。

### 4. 用机制兜底差异

团队风格天然不同，追求一致不现实。用**交付契约、里程碑检查、复盘纪要**把协作规则显性化。契约不是不信任，是对协作的最低保护。

---

## 核心逻辑

```
人际摩擦 → 诊断根因（信息/结构/激励） → 可执行动作 → 追踪结果
而不是：
人际摩擦 → 情绪反应 → 道德评判 → 等别人解决
```
