# 远程/混合办公的协作节奏

## 一句话速记

远程/混合办公的核心挑战不是"效率"，是**信息不对称和信任衰减**。三个必须做的事：① 异步优先——所有重要讨论必须有书面结论（会议录音不算，要有人写纪要）；② 强制同步节点——每周固定时间全员在线（站会、周会），其他时间弹性；③ 主动 over-communicate——远程环境下，没人觉得你"说太多了"，只会觉得你"不知道在干嘛"。

## 通俗解释（5 分钟版）

```
办公室协作 vs 远程协作的本质差异：

办公室：
  - 你转头就能问同事一个问题 → 信息即时共享
  - 你在白板上画个图 → 路过的人看到参与讨论
  - 你加班到很晚 → 同事看到觉得你很拼
  → 信息靠环境共享，信任靠物理存在建立

远程：
  - 你发条消息可能要等 2 小时才回复 → 信息延迟
  - 你的工作过程别人完全看不到 → 信息黑洞
  - 你做了很多但没人知道 → 信任慢慢磨损
  → 信息靠主动传播，信任靠稳定输出建立

所以远程协作的核心不是换个工具（Zoom/Slack），
是换一套信息流动的方式。
```

## 关键细节

### 异步优先（Async-first）

**默认 async，同步只是例外**：

```
规则 1：任何讨论的结论必须落在文字上
  会议结束 ≠ 讨论结束
  会议结束 = 有人在群里/文档里发了一条纪要（3-5 条 bullet），
  没参与会议的人也能知道结论

规则 2：重要决策用文档协作，不用会议
  "我们能不能开会讨论一下这个？"
  → 改成："我把方案写了一个文档，大家 async review，
    周五前给意见，有分歧再开会。"
  
规则 3：信息默认公开，不设权限
  - 设计文档全团队可见（不只是当事几个人）
  - 周报、复盘、决定都被搜索到
  - 新人能自己搜到去年的方案为什么不采用，不用一个个问
```

### 强制同步节点

**弹性工作 ≠ 没有固定节拍**：

```
每日：
  - 站会（15 分钟，摄像头必须开）
  - 核心时间窗口 4 小时（如 14:00-18:00），全员在线，
    这段时间内消息回复 < 15 分钟，方便快速协作

每周：
  - 周会（45 分钟，不只是汇报，要讨论 1-2 个具体议题）
  - TL 的 1on1（每人单独 30 分钟，仍然每周一次）

每月：
  - 全员 demo day 或技术分享（拉齐信息面，建立团队感）

不要做的事：
  ✗ 站会变成每人念经 2 分钟（"昨天写代码，今天继续写代码"）
    → 站会应该关注：有谁被 blocked 了？有谁在做和计划不符的事？
  ✗ 每天全是会，把"弹性"变成"全天候待命"
    → 上午是深度工作时间，下午是协作时间
```

### 反远程疲劳

**远程工作最大的问题是"孤独感"和"边界模糊"**：

```
TL 要做的事：
  1. 每周至少一次非工作主题的团队小活动
     - 线上小游戏（15 分钟，不是 1 小时）
     - "周五咖啡角"——打开摄像头随便聊，不聊工作
     - 每月一次线下聚餐（如果同城）
     
  2. 关注"静默者"
     - 站会上不发言的人 → 1on1 里问"我看你最近会上不太说话，
       有什么原因吗？"
     - 消息很少的人 → "没事吧？需要我 check 一下吗？"
     - 远程你不能靠表情和肢体判断情绪，只能靠主动问

  3. 明确下班边界
     - "我不期望你在 20:00 之后回消息"
     - TL 自己不要 22:00 发消息（你发了就是在暗示别人也要回）
     - 如果确实晚上工作，用 Slack 的 schedule send 功能设到明早 9:00 发
```

### 混合办公（Hybrid）的特殊挑战

```
混合 = 一部分人在办公室，一部分人在远程

最大的坑：办公室的人形成了"第一梯队"，远程的变成"二等公民"
  - 办公室里白板讨论做了决策，远程的完全不知道
  - 办公室里同事私下吐槽某个方案，远程的没听到
  - 升职时办公室的人"存在感更强"

必须执行的规则：
  1. 只要有一个人远程，所有会都开线上
     （"我们几个在会议室，XX 你拨进来"——XX 是二等公民）
     正确做法：每个人自己拨进来，包括在办公室的人

  2. 白板上的讨论拍了照发到群里，不能只有拍照的人知道

  3. 远程和办公室的晋升标准完全一样
     （如果不一样，你团队里的远程的人会全部离职）
```

## 延伸追问

- **Q：远程怎么判断一个人是真的在干活还是摸鱼？**
  → 不要用"在线时长"衡量，用"输出频率和质量"衡量。如果 TA 代码按时提交、MR 质量稳定、1on1 能说出本周做了什么，TA 有没有在"规定时间"工作不重要。反之，如果输出持续下降，不管是办公室还是远程都要干预。
- **Q：跨时区团队怎么协作？**
  → 核心挑战是"同步窗口"。做法：① 找出每天 2-3 小时的重叠窗口，所有实时协作安排在这个窗口内；② 其他时间完全异步；③ 决策权下放——不能让东八区等西五区的人醒了才能做决定。团队拆成时区小组，各小组在自己的白天有决策权。
- **Q：远程团队怎么建立"团队文化"？**
  → 文化不是团建做出来的，是日常工作里的微小选择积累的。远程环境中文化体现在：你代码 review 的语气是什么样的？有人犯错时你的第一反应是什么？决策是怎么做的（TL 拍板还是大家一起讨论）？做好这些，比办 10 次线上团建都管用。

## 我的记法

- **三大支柱**：异步优先（落在文字上） + 强制同步节点（站会/周会/1on1） + over-communicate（主动说）
- **混合办公铁律**：只要有一个人远程，就全员线上
- **TL 的仪容**：不要 22:00 发消息——你发了，别人就觉得必须回
- 一句话：**「远程协作不是你选什么工具，是你怎么设计信息流动和信任建立」**
