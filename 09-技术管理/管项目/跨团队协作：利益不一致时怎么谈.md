# 跨团队协作：利益不一致时怎么谈

## 一句话速记

跨团队协作的核心不是"沟通技巧"，而是**找到双方利益的交集点**——对方 TL 也有 TA 的 OKR、排期压力、老板要求。你谈不下来说明你还在谈"我的诉求"，没在谈"你的诉求在我这里也能得到满足"。四个步骤：① 先搞清楚对方真正的 OKR 和约束（不猜，可以问）；② 把你的需求翻译成 TA 的 OKR 的加速器；③ 给交换不是索要——"你需要我这边做什么作为回报"；④ 如果完全没交集，升级——不是告状，是让两个团队的上级一起做 trade-off。

## 通俗解释（5 分钟版）

```
失败的跨团队沟通：

你："我们项目需要你们团队这周把接口给我们。"
对方 TL："我们这周已经排满了。下个月吧。"
你："但我们项目是老板亲自盯的 P0 啊。"
对方 TL："我们项目也是老板盯的 P0。"

→ 两个 P0 对撞，变成了比谁声音大。最后比的是谁更敢升级。

成功的跨团队沟通：

3 周前你就找对方 TL 喝咖啡：
你："下个月你们团队的大方向是什么？这季度压力最大的是什么？"
对方 TL："我们 Q2 核心目标是 XX 平台迁移，所有资源都在这上面。"
你："了解了。我们下一个项目可能会需要你这边的接口改造，
     我看看能不能和我们这边做的结合起来——要不我先出个方案，
     尽量让接口改动量小，对齐你们自己的迁移方向？"
对方 TL："可以，提前两周给我就行。"
你："好，如果有我能帮你这边推进的，你随时说。"

→ 你在对方的 OKR 里找了一个你刚好能帮上忙的切入点。
  从"你来帮我"变成了"我们互相帮"。
```

## 关键细节

### 第一步：理解对方的棋盘

**搞清楚这些：**

```
1. 对方团队的 OKR / 季度重点是什么？
   → 可以问 TA 的 TL："你们这季度的重点是哪几件事？"

2. 对方的人力约束是什么？
   → "你们现在几个人？有谁在休假吗？关键人是谁？"

3. 对方被谁催得最紧？
   → 不是你的老板，是 TA 的老板在催 TA 什么？

4. 你的事在 TA 的优先级列表里天然排第几？
   → 你们之间没有直接利益时，大概率排在 TA 自己的事之后。
     这不是 TA 坏，这是 TA 的 KPI 决定的。
```

### 第二步：把你的需求翻译成 TA 的需求

```
你的需求              翻译成对方的收益
────────────────────────────────────────────
"给我一个接口"          "这个接口对接上了，我这边可以
                        分担你团队现在手动的 XX 工作"

"提前两周同步排期"      "我提前告诉你我的时间线，
                        你排你自己的事时能避开冲突"

"帮我们 review 方案"    "你越早看方案，越能确保方向跟
                        你们平台一致，后面返工越少"

"这周帮我做 X"          "做 X 能帮你减少 Y 这个你一直
                        头疼的问题"
```

**如果找不到对 TA 的收益怎么办？**：
有时候确实没有——这是在帮你，不是在帮 TA。那就直接承认：
"这件事确实对你这边直接收益不大。我记下了，下次你需要我帮的时候，优先级拉满。"

### 第三步：交换，不是索要

```
每次提请求时，附带一个问题：
"你需要我这边做什么来配合？"
"有什么是我这边可以帮你分担的？"

具体可以交换的东西：
  - 人力：我的人帮你 review 代码，你的人帮我联调
  - 时间：我这周帮你插队一个紧急 fix，你下周帮我提前一个接口
  - 信息：我告诉你我们 Q3 的方向（帮你提前规划），你帮我推进这次合作
  - 影响：下次你老板问起你团队表现，我在场夸
```

### 第四步：什么时候该升级

```
升级不是告状。升级是"我们一起去找有决策权的人做决策"。

应该升级的情况：
  ✓ 双方利益完全没交集，而且这件事必须有人做决定
  ✓ 你的合理请求被多次推脱（3 次以上）
  ✓ 对方答应了但是完全不推进（和答应的时候不一样）

升级时的话术：
  "我们俩都想做好各自的项目，但确实资源有冲突。
   我们一起去跟 XX 老板聊一下吧——我们各自说清楚自己的
   情况和约束，让老板帮我们看到我们可能没看到的方案，
   或者帮我们做取舍。"
  
  → 这不是"我去告你状"，是"我们一起找人帮忙"。
```

### 关系银行账户

```
在日常协作之外，定期"存款"——不涉及利益的主动帮忙：

  - 对方的线上问题你去主动帮忙
  - 你的经验分享主动抄送对方团队
  - 对方 TL 在群里问一个技术问题，你认真回复
  - 在会议上提一嘴对方团队做了 xx 挺好的

"存款"多的时候，你偶尔取一次（提需求），
对方不会斤斤计较。

"存款"为零的时候你去取，就是干巴巴的利益谈判——
而且你手里没筹码。
```

## 延伸追问

- **Q：如果对方 TL 就是不好说话，人尽皆知的难搞？**
  → 不要绕开 TA——TA 会更不满。用升级路径但不敌对："我理解你的顾虑。这件事我们俩确实不好决定，我们约上 XX 老板一起聊 15 分钟，让老板帮我们权衡一下？"——难搞的人通常也怕被升级，知道你愿意升级后反而会软化。
- **Q：跨团队的工程师之间直接沟通总是摩擦怎么办？**
  → 可能是你没给团队设定跨团队协作的规则。和对方 TL 一起对一下："我们俩各自跟团队说清楚——有问题先找我和 XX 对齐，不要直接在 MR 里吵。"TL 之间的信任建立后，工程师的摩擦会大幅减少。
- **Q：对方团队做了一件损害我们利益的事（比如擅自改了接口），怎么处理？**
  → 先私下找对方 TL 确认事实——可能是无意的。如果是故意的，问原因——可能对方也被逼急了。如果属实并且影响大，升级到共同的上级。不要让自己的人直接去对方团队吵架。

## 我的记法

- **四步法**：了解对方 OKR → 翻译成本收益 → 给交换 → 无交集就升级
- **银行账户**：平时多存（主动帮忙），偶尔取（提请求）
- **升级不是告状**：是"一起找有决策权的人帮我俩做 trade-off"
- 一句话：**「对方 TL 也有TA 的 OKR 和老板——你的需求说不动 TA，直到你帮 TA 说动 TA 的老板」**
